## Documentation Standards

All documentation follows these principles:
- **Audience-focused**: Tailored to specific user types
- **Action-oriented**: Provides clear steps and examples
- **Comprehensive**: Covers all major features and use cases
- **Current**: Reflects the latest system capabilities
- **Searchable**: Well-structured with clear headings

## Getting Help

1. **Check relevant documentation section** for your use case
2. **Search documentation** using your browser's find function
3. **Review logs** in `monitoring/logs/` for troubleshooting
4. **Check configuration** in `config/config.ini.example`
5. **Report issues** via GitHub Issues if documentation is unclear
